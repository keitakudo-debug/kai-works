# KAI WORKS - フリーランスサイト

「AIで、あなたの『面倒』をもっとラクに。」をコンセプトにした、
ホームページ制作・業務効率化アプリ制作の1ページ構成サイトです。

## ファイル構成

```
site/
├── index.html      本体（すべてのセクションはここに書かれています）
├── css/style.css   デザイン（色・余白・レイアウト）
├── js/main.js      スマホメニュー・スクロール演出・お問い合わせフォーム
└── images/         avatar.svg（プロフィールのイラスト）
```

## まずはブラウザで見てみる

`index.html` をダブルクリックするか、ブラウザにドラッグ＆ドロップするだけで確認できます。
サーバーは不要です。

## 差し替えが必要な「仮」の部分

検索しやすいように、目印になる言葉を書いています。`index.html` を開いて
以下のキーワードで検索（Ctrl+F）し、内容を差し替えてください。

| 場所 | 目印 | 内容 |
|---|---|---|
| お問い合わせ先 | `keita611210@gmail.com` | 反映済みです。`js/main.js` の送信先アドレスです。変更したい場合はここを書き換えてください |
| プロフィール画像 | `images/avatar.svg` | 反映済みです（顔写真ではなくイラスト）。差し替える場合はこのファイルを置き換えてください（推奨：縦長・4:5比率） |
| ヒーローのスクリーンショット | `screenshot準備中` | 実際に作ったアプリの画面ができたら、CSSのモックアップ（`.mockup-laptop` 内）を実際の画像に差し替えると、より説得力が出ます |
| 制作実績 | `works-note` の注記文 | 実際のスクリーンショットができたら、`work-thumb` の絵文字を `<img>` タグに差し替えてください |
| 料金 | `10,000円〜` など | 反映済みです。金額や内容を変えたくなったら `#pricing` セクション内を直接編集してください |
| ロゴ・サイト名 | `KAI WORKS` | ヘッダー・フッター・タイトルタグにあります。屋号が決まったら差し替えてください |

### CSS・JSが反映されないとき

CSSやJSファイルを更新しても変化が見られないときは、ブラウザがファイルをキャッシュしている
可能性があります。`index.html` 内の `css/style.css?v=3` や `js/main.js?v=2` の `v=` の数字を
増やす（`v=4` など）と、確実に最新の内容が反映されます。上記の手順5でFormspreeのURLを
書き換えたときも、もし反映されなければこの方法をお試しください。

## お問い合わせフォームについて（要・設定）

フォームに入力して送信すると、自動で `keita611210@gmail.com` にメールが届く仕組みに
なっています。ただし無料の外部サービス「[Formspree](https://formspree.io)」と連携する
必要があり、**このアカウント登録だけはご自身で行ってください**（Claudeはアカウント作成の
代行ができないルールになっています）。5分ほどで終わります。

### 設定手順

1. [formspree.io](https://formspree.io) にアクセスし、`keita611210@gmail.com` で無料登録する
2. ログイン後「+ New Form」から新しいフォームを作成する（名前は「KAI WORKS お問い合わせ」など何でもOK）
3. 作成すると `https://formspree.io/f/xxxxxxxx` のようなURL（Endpoint）が発行されるのでコピーする
4. Formspreeから `keita611210@gmail.com` 宛に確認メールが届くので、メール内のリンクをクリックして認証する（これをしないとメールが届きません）
5. `index.html` を開き、`https://formspree.io/f/YOUR_FORM_ID` の部分を、3でコピーしたURLに書き換えて保存する（1箇所だけです。Ctrl+Fで `YOUR_FORM_ID` を検索すると見つかります）

これで、フォームに入力→送信ボタンを押す→ `keita611210@gmail.com` に内容がメールで届く、
という流れになります。無料プランは月50件まで送信できます（個人利用なら十分な量です）。

設定が済むまでの間は、送信ボタンを押すと「送信に失敗しました。keita611210@gmail.com まで
直接ご連絡ください」というメッセージが表示されます（エラーではなく、想定どおりの動作です）。

## 公開（ホスティング）したくなったら

無料で公開できるサービスの候補です。いずれも `site` フォルダの中身をアップロードするだけで公開できます。

- **Netlify** … `site` フォルダをドラッグ＆ドロップするだけで公開できて一番簡単
- **Vercel** … GitHubと連携すると更新のたびに自動で公開される
- **GitHub Pages** … 無料・独自ドメインも設定可能、GitHubに慣れていれば手軽

準備ができたら「公開したい」と声をかけてもらえれば、一緒に進められます。
